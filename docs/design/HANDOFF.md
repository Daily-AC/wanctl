## 3. 现在长什么样

`site/` 全站 332K（含 4 个自托管 woff2）。零构建、零依赖、纯静态。

- `site/index.html` — 六段：首屏（白）→ 审批凭证（深）→ 设备列表（浅灰）→
  **身份核对（深）** → 安装（白）→ 页脚
- `site/assets/app.css` — 苹果语法：单一 Action Blue、字号阶 56/40/17、负字距、
  无 500 字重、整幅 tile 颜色变化即分隔线、唯一投影只给三个「产品渲染」
- `site/assets/app.js` — 首屏双屏里跑的活 demo（终端 + 手机审批），`window.__demo` 验收接口
- `site/assets/fonts/` — Schibsted Grotesk（展示/正文）+ JetBrains Mono（标识符）。
  **必须自托管**：ls 在大陆，`fonts.googleapis.com` 对访客不可靠。
  `archivo-*.woff2` 是 LOTO 版遗留，现已无引用，**下次可删**

主体解法（这是本轮最关键的设计判断）：**苹果的语言是摄影优先的，而 wanctl 没有硬件可拍。**
不编造不存在的产品，改用 CSS 画笔记本和手机外壳、**里面跑真实的活界面**。

## 4. 已验证的事实（别重测）

- **策略语义**忠实移植自 `internal/policy` 的 `matchCommand` + `ruleMatchesShell` exec 分支：
  规则记的是**命令**不是设备。签「一直允许」后，第三轮换成 `nvidia-smi` **会重新问**。
  六条分支在真浏览器里跑过，落点全对。
- **对比度是算的**（`tools/contrast.py`）。别凭记忆写数字——本轮我写错过三个。
  `ink-3 #86868b` 实测 3.62:1，**不得承载文字**。
  09-04 把这个工具改成**直接读 `app.css` 的 `:root`**：它原先还在验 LOTO 那版早已下线的
  黄/朱红，换过调色板却没人发现。顺手补了两对从来没验过的——深色屏上的正文
  （15.46）和次级文字（6.54），都通过。
- **headless Chrome 把窗口钳到最窄 500px**，`--window-size=390` 是按 500 排版再裁到 390，
  看起来像整页横向溢出其实是量具的锅。绕法已收编成 `tools/shot.sh`。
- **部署路径已查清，无需再研究**：`wc.z10.dev` 是一级子域，命中已有泛域名
  `*.z10.dev`（橙云 + CF Universal SSL）→ **不用加 DNS、不用签证书**。
  静态站按 2026-08-06 政策放 **ls**，hk 只做 TLS 终止 + 反代。见 `fleet-deploy` skill。

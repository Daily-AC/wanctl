# TAGOUT — wanctl 的设计系统

last-reviewed: 2026-09-03

这份文件是 wanctl **两个 web 表面的唯一视觉真源**：产品官网（`site/`，部署到 wc.z10.dev）
和设备门户（`internal/portal/`）。两边取同一套 token、同一套字体、同一套语法。
改视觉先改这里，再改实现。

本文**不维护**：文案正文（官网在 `site/`，门户文档在 `docs/portal/`）、
组件的具体实现（读代码）、部署方式（见 `docs/self-hosting.md` 与舰队规范）。

---

## 1. 场景句

> 白天，车间的配电柜前。柜门上挂着一把锁和一张写了名字的牌子——
> 机器通电之前，挂牌的那个人必须亲手把牌摘下来。
> 冷白的漆面，黑色的丝印，安全黄的牌。

明暗由这句话定：**浅色**。不是「亮色模式」，是白天的车间。

## 2. 主张

wanctl 是软件版的**挂牌上锁（lockout-tagout）**。

工业安全里，一台机器被检修时要挂锁挂牌，牌上写着挂牌人的名字；
机器要重新通电，必须由**挂牌的那个人亲手摘牌**——别人不能代劳，管理员也不能。
这正是 wanctl 的策略模型：设备默认上锁，agent 要动它，得先在设备主人这儿摘牌。

所以视觉语言不是贴在产品上的装饰，**它就是产品语义本身**。这是这套设计和
「又一个深色技术站」的根本区别。

执行落在**精密仪器**的 register（冷白搪瓷、丝印、铭牌），不是工地警示牌的
register（反光条、危险斜纹、橙色塑料）。差别就是这套东西成立还是变成 kitsch。

## 3. 色彩策略

**克制**：中性冷白 + 黑，单一强调色（安全黄）在静息态 ≤ 10%。

唯一的例外是**「等你决定」这个状态**：此时黄色升格为大面积色场。
这是状态升级，不是第二套配色——页面上任何时刻只要看见大片黄，就意味着有事在等人。

朱红只用于**撤销、拒绝、离线**这三类负向事实，永远不做装饰。

### Token

```css
--ground:   oklch(0.972 0.002 250);  /* 冷白墙面。hue 250 避开暖中性禁区 */
--surface:  oklch(0.988 0.0015 250); /* 搪瓷牌面，比墙面亮 */
--ink:      oklch(0.185 0.004 250);  /* 丝印黑，微冷 */
--ink-2:    oklch(0.485 0.006 250);  /* 次级文字 */
--ink-3:    oklch(0.640 0.005 250);  /* 三级/占位 */
--line:     oklch(0.885 0.004 250);  /* hairline */
--line-2:   oklch(0.815 0.005 250);  /* 强分隔 */

--tag:      oklch(0.874 0.184 92);   /* 安全黄 ≈ #FFD100。挂牌，等你决定 */
--tag-deep: oklch(0.780 0.170 88);   /* 黄的按压/边缘 */
--vermil:   oklch(0.552 0.196 30);   /* 朱红 ≈ #CE3B1D。撤销、拒绝、离线 */
--live:     oklch(0.605 0.155 150);  /* 在线绿，只做 6px 状态点，不做面 */
```

### 实测对比度（2026-09-03，`tools/contrast.py` 算的，不是估的）

| 前景 / 背景 | 比值 | 判定 |
|---|---|---|
| `ink` / `ground` | 17.19 | 通过 |
| `ink-2` / `ground` | 5.90 | 通过 |
| `ink-3` / `ground` | **3.10** | **不通过正文 4.5** |
| `ink` / `tag` | 12.65 | 通过 |
| `vermil` / `ground` | 4.89 | 通过 |
| `live` / `ground` | 3.34 | 通过（非文字，阈值 3） |

**结论：本系统只有两档文字灰（`ink` 与 `ink-2`）。**
`--ink-3` 只用于装饰笔画和状态点，**任何情况下不得承载文字**。

近白底上塞不进三档达标的灰——第三档要么不达标，要么和第二档差不出来。
所以本系统里「更次要」由**字号和字距**表达，不由淡色表达：丝印标签是 12px、
字距 0.14em、字宽 78% 的黑字，不是灰字。这也更忠于隐喻：搪瓷上的丝印只有一种黑，
靠印得小来退居次要。

黑压黄：12.65:1。灰字**永远不压黄**（会发糊），黄底上只允许 `--ink`。

## 4. 字体

两家，落在真实对比轴上（工业 grotesque × 等宽），不是两个几何 sans。

| 角色 | 字体 | 说明 |
|---|---|---|
| 展示 / UI / 丝印标签 | **Archivo**（可变，weight 100–900 + width 62–125） | 一家多字重多字宽，Omnibus-Type 的工业 grotesque。丝印大写标签用 width 75 + 字距 0.14em；大标题用 width 88 + weight 800 + 字距 -0.03em |
| 标识符 / 命令 / 铭牌 | **JetBrains Mono**（400 / 700） | hostname、指纹、路径、命令、版本号一律等宽。铭牌上的机器名就是这个 |

**自托管，不走 Google Fonts。** ls 在大陆，`fonts.googleapis.com` 对访客不可靠。
woff2 落在 `site/assets/fonts/`，门户的那份走 `go:embed`。

CJK 不加载网络字体，回退系统：`"PingFang SC","Hiragino Sans GB","Microsoft YaHei"`。

字阶模数 **1.333**（完全四度）：12 / 13 / 16 / 21 / 28 / 37 / 50 / 67 / 89 px。
深底浅字不存在（本系统全浅底），行高不额外补偿。

## 5. 结构纪律（来自「一千年后」那条）

这是本系统最容易被违反、也最决定成败的一节。

- **没有卡片。** 内容不装在带边框或阴影的盒子里。分组靠对齐、hairline、留白和视觉重量。
- **唯一允许存在的「物体」是设备牌。** 因为它在隐喻里是一块真实的搪瓷牌，不是一个内容容器。
  牌有材质、有厚度、有锁孔；除它以外页面上不该再出现第二种有边框的矩形。
- **留白是结构，不是余量。** 大面积的空冷白墙面是这套东西的骨架。
- 圆角：牌 2px，其余 0。按钮不做胶囊。
- 阴影：只有设备牌允许一层极短的接触阴影（≤ 4px 模糊，用于坐实它是块实物）。
  其余一律无阴影。`1px solid` 与宽模糊阴影永不同时出现在一个元素上。

## 6. 审批凭证（来自工程图纸标题栏）

每一次「摘牌」都留下一条**标题栏式的凭证**，而不是一条 toast：

```
APPROVED BY   张以琳            DATE   2026-09-03 14:22:07
DEVICE        zyl               VIA    claude@mac-studio
COMMAND       python scripts/train.py --epochs 3 --resume
SCOPE         once                     REV  Δ1
```

对齐的键值、等宽的值、hairline 分隔。**拒绝**的凭证同形，`SCOPE` 位置写 `denied`，
右侧带朱红修订云标记。这套凭证在官网是演示，在门户是真实审计记录——同一个视觉语法。

## 7. 动效

- 只用 ease-out 族（quart / quint / expo）。不用 bounce、elastic。
- 不动 layout 属性；只动 `transform` / `opacity` / `clip-path` / `filter`。
- **摘牌**是本系统的签名动作：牌绕顶部挂点旋转落下 + 淡出，320ms `cubic-bezier(.2,.8,.2,1)`。
- 「等你决定」的黄不做呼吸渐变，做**两帧步进闪烁**（`steps(2)`），像继电器不像呼吸灯。
- 每条动画配 `prefers-reduced-motion: reduce` 降级为瞬时切换，流程不变。
- 内容可见性不绑在 class 触发的 transition 上：无头渲染下首屏必须完整可见。

## 8. 硬禁（本项目额外的，在 rules.md 之上）

- 不出现危险斜纹（`repeating-linear-gradient`）、反光条、橙色塑料这类工地 kitsch。
- 黄色不做渐变、不做发光、不做透明叠加；它是印上去的漆，不是光。
- 不出现第二种矩形容器（见第 5 节）。
- 不出现深色模式。本系统只有白天。
- 其余全部遵守 `~/.claude/skills/design-dna/rules.md`。

## 9. 两个表面的差异

同一套 DNA，两种密度：

| | 官网 `site/` | 门户 `internal/portal/` |
|---|---|---|
| 密度 | 疏。首屏只有一个主角（设备牌一排） | 密。表格行距紧，一屏看完六台 |
| 牌的尺寸 | 大，有材质细节和锁孔 | 小，退化成一行铭牌 + 一个状态点 |
| 语言 | 英文为主，中文可切 | 中文（设备主人是中文用户） |
| 字号基准 | 16px | 14px |

# wanctl v0.1.0

The first security-reviewed wanctl release.

## Highlights

- End-to-end encrypted remote exec, file transfer, persistent console sessions,
  device pairing, local policy, audit logs, portal approval, and Feishu SSO.
- WebSocket and reverse-proxy-compatible HTTP long-poll transports.
- Signed cross-platform updates for Linux, macOS, and Windows.
- Offline Ed25519 release signing. Installers and binaries fail closed if the
  manifest, signature, size, or SHA-256 does not match.
- Non-root container runtime, pinned build images, SBOM generation, dependency
  vulnerability scanning, and container image scanning.

## Install

Download `install.sh` or `install.ps1` from this GitHub release. Do not obtain an
installer from the relay: the GitHub release is the independent trust bootstrap.

Public release: <https://github.com/OWNER/wanctl/releases/tag/v0.1.0>

The Unix installer requires `openssl` 1.1.1 or newer. The Windows installer
requires PowerShell and `openssl` on `PATH`.

## Compatibility

- Linux: amd64, arm64
- macOS: amd64, arm64
- Windows: amd64

Production uses `https://relay.example.com` with HTTP long-poll.
The v0.1.0 binary contains an earlier raw-IP/WebSocket default, so v0.1.0 users
must set `WANCTL_RELAY=https://relay.example.com` and
`WANCTL_TRANSPORT=http`. The raw IP is not a supported v0.1.0 production entry
point.

# wanctl v0.1.8

Fixes Android support in Termux, which v0.1.7 shipped broken.

## The regression

v0.1.7 added an `android/arm64` artifact and, with it, a workaround for
Termux's argument-vector duplication: Go's Android target is always dynamic
PIE, so Termux's exec interceptor re-runs the binary through the dynamic linker
and prepends the program's absolute path to `argv`, shifting every argument one
slot late.

The workaround identified the duplicate with
`os.SameFile(stat(argv[0]), stat(argv[1]))`. That holds when `argv[0]` is
`./wanctl` or an absolute path — both of which the pre-release device checks
used — but not when it is a bare `wanctl` resolved from `PATH`, which does not
stat relative to the working directory. A bare command name is precisely what
one types after installing, so on v0.1.7 the installed binary answered every
invocation with `unknown command "/data/data/com.termux/files/usr/bin/wanctl"`.

The marker is now that `argv[1]` is an absolute path to a regular executable
whose base name matches `argv[0]`'s, which covers all three forms `argv[0]` can
take. A subcommand is never an absolute path, so no valid argument is swallowed.

Verified on a vivo PA2353 through the real one-line installer — bare, relative
and absolute invocation, plus a subcommand with flags.

## Upgrading

Only Android in Termux is affected; every other platform is byte-identical in
behaviour. On a v0.1.7 Termux install, `wanctl update` cannot be typed as
`wanctl update` (that is the bug), so run it by path once:

```sh
$PREFIX/bin/wanctl update
```

or re-run the one-line installer.

Devices installed over `adb` are not affected: nothing intercepts exec there,
so v0.1.7 works as documented.

## Process note

The bug was found by running the published installer on a device instead of a
locally built binary. The code was identical either way — what differed was the
invocation, and every earlier device check had used a path form. A release that
adds a platform is not verified until the platform's ordinary install-then-run
path has been walked on hardware.

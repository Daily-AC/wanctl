# wanctl v0.1.8 — withdrawn, never published

The `v0.1.8` tag exists and its pipeline ran, but **no GitHub Release was
published from it and it was never deployed**. Nothing served it. Do not install
it.

It carried one fix — Termux's duplicated `argv[0]` for a bare command name —
and testing that fix on the device immediately surfaced three more problems in
the same area, one of which can destroy a rooted device (`wanctl update`
resolving its own path to `/apex/com.android.runtime/bin/linker64` and
overwriting it). Shipping a release known to contain that was not worth the tidy
version number.

The tag could not be deleted (protected tags refuse it), so it is recorded here
instead of quietly disappearing.

All four fixes ship together in **v0.1.9**.

# wanctl v0.1.1

This patch release fixes reliability issues found during production launch
verification.

## Fixes

- Batch HTTP tunnel writes, reducing large file transfers from roughly one
  relay request per TLS record to bounded 256 KiB uploads.
- Serialize WebSocket relay piping so one connection pair has exactly one
  bidirectional copy loop. This prevents intermittent TLS `bad record MAC`
  failures during repeated sessions.
- Route loopback-only scanner proxies through Docker host networking in CI.

## Install

Download `install.sh` or `install.ps1` from this GitLab release. Do not obtain an
installer from the relay: the GitLab release is the independent trust bootstrap.

Public release: <https://g.***REMOVED***.com/ai-native/wanctl/-/releases/v0.1.1>

The Unix installer requires OpenSSL 1.1.1 or newer. The Windows installer
requires PowerShell and `openssl` on `PATH`.

## Compatibility

- Linux: amd64, arm64
- macOS: amd64, arm64
- Windows: amd64

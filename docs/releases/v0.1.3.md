# wanctl v0.1.3

This patch release makes installation a single command again and fixes agent
shutdown on the WebSocket transport.

## Fixes

- Install with one line. Both installers now carry the relay they were built
  for, so `WANCTL_RELAY` is only needed to point at a different one.
- Verify releases without a separate OpenSSL install. The manifest now carries a
  second signature, RSA-3072 over the identical bytes, for the install scripts
  only. macOS ships LibreSSL, whose `pkeyutl` cannot verify Ed25519, and
  PowerShell 5.1 has no Ed25519 at all, so `curl … | sh` failed on a stock Mac
  and `irm … | iex` required a slow OpenSSL download on Windows. `wanctl update`
  still verifies Ed25519 inside Go, so binaries from v0.1.2 and earlier keep
  upgrading normally.
- Stop a WebSocket agent with `wanctl stop`. The control loop blocked in a
  decode that never returned while the device was idle, so it ignored SIGTERM
  entirely and systemd or launchd had to wait for its stop timeout and SIGKILL.
- Serve `install.sh` and `install.ps1` from the relay again, for colleagues
  without a GitLab account. They come from the same signed release directory as
  the binaries.

## Install

```sh
curl -fsSL https://wanctl-relay.***REMOVED***.***REMOVED***.com/install.sh | sh
```

```powershell
irm https://wanctl-relay.***REMOVED***.***REMOVED***.com/install.ps1 | iex
```

The strongest bootstrap is still to download `install.sh` or `install.ps1` from
this GitLab release rather than from the relay: a compromised relay could serve
a matching script and public key. See `docs/release-signing.md`.

Public release: <https://g.***REMOVED***.com/ai-native/wanctl/-/releases/v0.1.3>

No OpenSSL installation is required on any supported platform. The Unix
installer uses whichever `openssl` is present, including the LibreSSL that macOS
ships; the Windows installer verifies with PowerShell's own RSA implementation.

## Compatibility

- Linux: amd64, arm64
- macOS: amd64, arm64
- Windows: amd64

Production uses `https://wanctl-relay.***REMOVED***.***REMOVED***.com` with HTTP long-poll.

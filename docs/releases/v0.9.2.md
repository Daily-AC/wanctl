# v0.9.2

Serves the hosted MCP endpoint at `/mcp`, the path AI hosts expect; `/wanctl-mcp`
stays as an alias for deployments whose edge proxy has already claimed the
`/mcp` prefix. Both paths reach the same handler and the same sessions.

Fixes the portal pairing card that outlived its request (#79). A device now
drops an expired pairing from its state snapshot and refuses a verdict for one,
the portal turns that refusal into a visible "expired or already answered"
message instead of a silent success, and the pairing deep-link overlay closes
on that answer and on Escape rather than covering the live approval list.

Upgrade relay and portal. No migration. Devices pick up the expiry change on
their next automatic update; older devices keep working, and the portal message
already applies to them.

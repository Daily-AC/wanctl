# wanctl v0.1.2

This patch release fixes agent lifecycle handling during self-update.

## Fixes

- Preserve ownership of agents launched by systemd, launchd, a Windows
  Scheduled Task, or another supervisor. After replacing the binary, wanctl
  now terminates the old agent through a detached helper and lets the original
  supervisor restart it with the same relay, transport, policy mode, identity,
  and environment.
- Add a restart loop to newly installed Windows Scheduled Tasks, whose native
  `ONLOGON` trigger does not restart a process that exits later.
- Probe Windows process handles so stale PID files are no longer treated as a
  live agent.

## Upgrade note for existing services

After installing v0.1.2 over v0.1.1 or older, run `wanctl service install` once
to migrate an existing OS service definition to the supervisor-aware form.
This one-time step is necessary because an updater from an older release cannot
contain the new lifecycle behavior. Fresh v0.1.2 installations need no extra
step.

## Install

Download `install.sh` or `install.ps1` from this GitLab release. Do not obtain an
installer from the relay: the GitLab release is the independent trust bootstrap.

Public release: <https://g.***REMOVED***.com/ai-native/wanctl/-/releases/v0.1.2>

The Unix installer requires OpenSSL 1.1.1 or newer. The Windows installer
requires PowerShell and `openssl` on `PATH`.

# 用 BFS 理解 wanctl 远程工作区

这组文档面向想理解系统架构、同时参与产品判断的开发者。按广度优先顺序读：先认识整个系统，再理解各部分如何合作；不要求先学 Go、PTY 或网络协议细节。

## 要改变的体验

AI 进入一台设备的项目后，后续命令和文件操作持续落在这个远端工作区。网络断开时显示远端不可用，显式退出后才结束这次远端工作。宿主能否把它自己的本地工具一并切换，是另一个集成边界。

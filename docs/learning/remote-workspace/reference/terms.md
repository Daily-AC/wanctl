# 术语速查：在这门课里，每个词指什么

这是课程参考表，用于统一讨论用语；它不代表任何读者已经掌握这些概念。需要解释背景时，回到对应课程。

| 术语 | 本课程中的含义 | 不要混同 |
| --- | --- | --- |
| 宿主（host / harness） | 组织模型、对话与工具调用的应用 | 模型本身；某个 MCP 服务 |
| 模型 | 根据目标与上下文选择下一步动作的推理组件 | 实际执行命令的进程 |
| MCP 服务 | 通过 MCP 暴露工具、接收调用并返回结果的服务 | 对整台电脑所有工具的自动接管 |
| 控制端 | 携带身份与请求、访问目标设备的一端 | 被控制的设备端 |
| Relay | 为控制端和设备提供连接转发的组件 | 保存所有 shell 状态的执行内核 |
| 设备端 agent | 在设备上进行身份与策略检查、管理执行和文件操作的进程 | 聊天窗口里的模型 |
| 工作区 | 设备端管理的一段工作：根目录、独立 shell 和执行记录 | 网络连接；整个文件系统沙箱 |
| 工作区引用 | 定位设备和工作区的完整标识，仍需有效授权 | 通行凭证；账号级默认目录 |
| shell | 解释命令并持有当前目录、环境等状态的进程 | 每次新启动的 Python 程序 |
| 项目根目录 | 文件工具解释工作区相对路径的基点 | shell 当前目录 |
| 执行任务 | 一次被设备受理、可以查询结果的命令 | 工作区的全部生命周期 |
| 命令请求编号 | 工作区账本用于找回与去重某次命令的标识 | MCP 的 JSON-RPC 消息编号 |
| OAuth 访问令牌 | 表示访问授权的凭据，有自己的范围与有效期 | 工作区绑定；设备证书 |
| 控制端身份 | wanctl 用来识别操作端的加密身份 | 人在网页中的显示名称 |
| 指纹 | 用于核对某个加密身份的摘要表示 | 文件内容的 SHA-256；操作许可 |
| 文件摘要 | 用于检查文件内容版本是否变化的 SHA-256 | 锁定文件；禁止其他人修改 |
| Output Schema | 描述结构化返回字段、类型与含义的契约 | 宿主审批开关；模型输出约束模式 |
| 去重 | 在执行记录仍保留时，识别已经受理的同一命令 | 跨任意重启的恰好执行一次 |
| PTY | 为交互式终端程序提供终端接口的一类机制 | 普通命令输出流；已实现的 wanctl 工作区能力 |

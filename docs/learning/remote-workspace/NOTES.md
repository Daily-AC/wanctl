# 课程编辑约定

这是一套供开发者自学的公开课程，不是某位读者的个人学习档案。遵循 Teach Skill 的目标、短课、原始资料、即时反馈和共享组件原则；没有证据时不写“读者已经掌握”。因此不预填 GLOSSARY.md 的个人掌握清单，也不创建 learning-records 活动日志。公开术语定义放在 reference/terms.md。

Markdown 是正文真源；构建器生成 Docs 页面和 lessons/*.html、reference/*.html 教学输出。共享组件在 assets/，站点通用排版继续复用 site/assets。课程正文目前为中文，英文界面明确提示尚未翻译；不伪造英文版本。

每次修订需检查原始资料、代码基线、全部内链、自检反馈和移动端。上线不需要为文档重发 wanctl 二进制。

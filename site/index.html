Nothing runs until you pull the tag.

wanctl hands an AI agent your machines across the public internet. Every command it sends stops at the device and waits for the person holding the tag. The relay in the middle only ever sees ciphertext.

Install on the machine you want to reach
curl -fsSL https://wanctl.dev/install.sh | sh

One Go binary: relay, portal, agent, controller and MCP server are all the same file. Windows uses install.ps1.

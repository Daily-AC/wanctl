Your machines. Your call.

wanctl lets your AI agent work on your own machines, across the internet.

› Hand wc.z10.dev to your agent.

Two lines on each machine.

Install, then start. Sign in once in the browser, paste the code back into the terminal, and the machine is in. 

curl -fsSL https://github.com/Daily-AC/wanctl/releases/latest/download/install.sh | sh
wanctl start

Straight from the GitHub release. Windows (PowerShell): irm https://github.com/Daily-AC/wanctl/releases/latest/download/install.ps1 | iex, then wanctl start. From mainland China, install from the official relay instead: curl -fsSL https://wanctl-relay.z10.dev/install.sh | sh (Windows: irm https://wanctl-relay.z10.dev/install.ps1 | iex).

If nothing is configured yet, the first start asks which relay to use: ours at wanctl.z10.dev (invite-only for now), or one you run. After that, wanctl help lists every command; your agent mostly needs wanctl peers and wanctl exec --target DEVICE "…".

The first time it touches a machine, it asks you.

Your agent hands you a link. Open it, check the fingerprint, and trust it. Once per machine; the link lasts five minutes.

After that, each machine follows its own setting.

  • Allow all Commands run on the spot. Every one is written to the activity log.
  • Ask me Each command waits on the device until you approve it in the portal. No answer in 60 seconds means no.

The AI in your browser can use it too.

Pick the way in by what the chat can do.

  • Takes connectors (MCP), like ChatGPT https://wanctl-relay.z10.dev/mcp Add it as a connector, then allow it once in the portal.
  • Can only read web pages https://wanctl-relay.z10.dev/webfetch Ask it to open this page. You approve a short-lived pass for one device.

An agent on your own computer talks to each device end to end encrypted; the relay only carries bytes it cannot read. A web AI's controller runs inside the relay, so the relay does see the commands it sends.

Open source. Run the relay yourself if you like.

Every device dials one relay. Use ours, or run relay, portal and Postgres from one compose file. Apache-2.0.

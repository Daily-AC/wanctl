# v0.15.0 — 安全加固：为接纳互不相识的用户做准备

这一版是安全版本。托管实例准备开始接纳互不认识的用户，我们按「任何一个账号都可能不怀好意」重新审了一遍 relay、门户、托管 MCP、设备端和部署。**自己部署的实例都应该升级。**

- **修复了门户与 relay 之间的一处身份校验缺陷。** 已登录的用户能通过特定的请求，让 relay 以另一个账号的名义签发令牌、改通知设置或建立共享。门户现在只转发每个操作需要的字段，relay 也会拒绝可能冒充身份字段的请求体。另外修了 refresh token 在并发兑换时可以用两次的问题。
- **一个账号拖不垮所有人。** relay 给隧道缓冲的数据设了按字节计的上限：每个会话方向、每个账号、全局各有一道。每个账号能同时打开的会话数、托管 MCP 会话数（没登录的会话闲置 10 分钟就回收）、OAuth 客户端注册数、同时进行的下载数都有了上限。`/dl` 下载改成从磁盘流式发送，不再把整个文件读进内存。托管 MCP 执行命令时边读边截断输出，设备打印再多，relay 也只保留要返回的那部分。
- **被中途杀掉的命令不再占着位置。** 控制端被强杀、崩溃或断网（比如 AI 工具超时）留下的会话，relay 会在大约一分钟内回收，即使设备那边还在等。`wanctl exec` 收到 SIGTERM 时也会像 Ctrl-C 一样通知设备停止命令。
- **撤销共享立刻生效。** 以前撤销后，对方已经建立的会话还能继续用；现在 relay 会当场断开。撤销掉的控制端再连上来，也必须重新配对，不会再被悄悄恢复信任。
- **设备自己的配置文件，任何写法都碰不到。** 在 macOS 和 Windows 上，大小写不同的路径、macOS 的 `/System/Volumes/Data` 路径、硬链接，以前能绕过「配置目录不可传输」的限制，现在按文件本身判断，一律拒绝。
- **远程工作区按命令真正执行的目录审批。** 持久 shell 用 `cd` 换过目录后，下一条不带 `--cwd` 的命令，按 shell 当前所在的目录匹配规则。
- **后台任务的输出只给发起它的控制端。** 别的控制端拿着 job ID 也读不到。
- **设备送来的文字不再能操纵你的终端或模型。** CLI 输出到终端时，会把设备输出里的控制字符显示成可见的转义；写进管道或文件时，字节保持原样。托管 MCP 返回给模型的内容也做同样的转义，`wanctl_read` 读出的文件内容除外（要留给 `wanctl_edit` 做精确匹配）。
- **通知卡片改成纯文本。** 飞书和钉钉卡片不再把别人写的内容当 markdown 渲染，比如访问申请的理由、设备名、命令。
- **门户更严格。** 页面不再允许内联脚本；`/api/devices/events` 已删除（门户早就不用它）；待审批聚合同一时间只查一次，最多 16 台设备并发，忙着的设备跳过。
- **令牌只从 `Authorization` 头读取。** URL 查询参数里的 `?token=` 不再被接受。通过 OAuth 授权签出的令牌，有效期跟着 refresh 链走（30 天，每次刷新顺延），不再永久有效。
- **安卓提权更稳。** 运行中打开提权通道会开始监听无线调试端口；发现的端口一天内都有效；探测时连接断了会先重连一次；adb 通道失效时，错误里会说明原因（重启、Wi-Fi 断开或换接入点会关掉无线调试，配对 7 天不用会被系统撤销）。

兼容性：新旧版本可以混用。仍在用 `?token=` 的非常老的客户端需要升级。后台任务只能由发起它的那个控制端查询：从托管 MCP 发起的任务，本地 CLI 查不到，反过来也一样。无数据库迁移，无新增环境变量。

# v0.22.2 — 工作区不再挡住自动更新，活动表合并连接并显示中文裁决

- **用过 `wanctl workspace` 的设备也能自动更新了。** 以前 agent 只要还开着工作区就当作「忙」，而工作区不会自动回收，所以用过一次工作区的设备之后一直不自动更新。现在只有工作区里有命令在等审批或在跑、或者有控制端经工作区连接连着时才算忙；空闲的工作区不挡更新。更新重启后空闲工作区里的 shell 状态（当前目录、环境变量）会丢，再用它会报「workspace unavailable」，重新打开一个工作区即可。
- **门户活动表把同一来源连续的连接合成一行。** 门户为了推送审批会定时重连设备，每次在活动表里记两行「建立连接」，表很快被刷满。现在同一个控制端、同一个结果的连续连接合成一行，写明次数和时间段（比如「10:12–14:12 · 建立连接 · 42 次」）；命令、文件操作和其他事件照旧一条一行。
- **中文界面的「裁决」列显示中文。** 以前显示设备写的英文原值（accepted、denied、rejected:unpaired 等），现在显示「已接受」「已拒绝」「拒绝：未配对」等；英文界面不变。切换语言时活动表跟着换，不用刷新。
- **门户发信成功也写日志。** 确认邮箱的信和申请通过的信，以前只在发送失败时写日志，现在发出去也写一行，记用户名和信件类型，不记邮箱地址。

兼容性：工作区那一条要设备 agent 升级到 v0.22.2 才生效。正被工作区挡着、还停在旧版本的设备不会自己升上来：重启一次 agent（`wanctl stop` 再 `wanctl start`，或重启它的服务、计划任务），重启后约一分钟内会自动更新。活动表和发信日志随门户生效。无数据库迁移，无新增环境变量。

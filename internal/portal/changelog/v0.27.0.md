# v0.27.0 — 门户能放到手机主屏幕，设备详情显示 wanctl 和 OpenCU 版本

- **门户可以添加到手机主屏幕。** iPhone 在 Safari 的分享菜单里选「添加到主屏幕」，安卓在 Chrome 菜单里选「添加到主屏幕」，之后从图标打开就是独立窗口，没有浏览器地址栏，刘海和底部横条不再挡住顶栏、弹窗和提示。iOS 的主屏幕应用和 Safari 各自保存登录状态，从图标打开后要单独登录一次。没有离线缓存、推送通知和安装提示。所有页面都在 412×915 和 390×844 两种手机尺寸、中英文下检查过，没有溢出和被截断的控件。
- **设备详情显示装的是哪个版本。** 每台设备显示 wanctl 版本，Windows 设备装了 OpenCU 时还显示 OpenCU 版本。设备列表不加版本列，只在 wanctl 落后最新正式版时显示一个「可升级到 vX.Y.Z」的小标记；比最新正式版还新的 beta 照实显示，不算落后。版本由设备注册时自己上报：v0.27.0 之前的 agent 不上报，显示「未知」，自动更新后补上。
- **`wanctl update` 的帮助改回英文**，和其他命令一致。

兼容性：新 agent 连旧 relay 照常注册，新字段被忽略；旧 agent 连新 relay 版本显示「未知」。一次数据库迁移 `015_device_versions.sql`（`devices` 表加三列，不回填），无新增环境变量。

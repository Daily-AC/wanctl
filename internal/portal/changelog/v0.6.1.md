# v0.6.1 — 修复 Android 首次启动失败

v0.6.0 在首次创建设备 ID 时使用硬链接，Android 普通应用沙箱会拒绝该操作，导致 agent 反复退出、界面一直显示连接中。

- Android 改为文件锁保护下的原子重命名，保留并发启动只能发布一个设备 ID 的保证；已有 ID、登录凭证和配置不会被替换。
- 本地设备身份文件失败会明确报错并停止重试，避免把永久错误显示成网络连接中。
- 用普通、不可调试 App 的 `untrusted_app` 沙箱复现旧版失败，并验证修复后的 16 进程并发创建、重启持久化和实际中继连接。

**直接更新即可，不要清除应用数据，也不需要更改提权或审批设置。**

# v0.30.0 — 限权令牌：只能在一台设备上跑一条命令

- **限权令牌。** `wanctl scoped-token create --device <设备> --command '<命令>'` 发一把令牌（`wcs_…`），给定时任务、webhook 这类只需要做一件事的程序用。它只能在这台设备上运行这一条一字不差的命令；换命令、多加参数、别的设备、传文件、看日志、开 shell、管账号都会被拒绝。有效期 1–365 天，默认 90 天，可以随时用 `wanctl scoped-token revoke` 撤销，门户的令牌列表里也能看到。设备身份在发令牌时固定，设备重新入网后旧令牌失效。用法见 `docs/scoped-token.md`。
- **Mac 手动更新后 agent 拉不起来时自动恢复。** launchd 偶尔停在退出码 78 不再重启 agent，以前要手动 `launchctl bootout` 再 `bootstrap`。现在 `wanctl update` 确认是这个服务、这个程序后自己做一次，再核对新版本；其他情况不动，并在报错里带上 launchd 的状态。
- **手机的 adb 报错说得准了。** adbd 在运行但连接断开时，提示重试，一直不行再重新配对；无线调试真的关了才让你去打开。连接中途断掉也不再只显示 `unexpected EOF`。
- **审批卡片。** 处理完的审批通知会消失，不再一直显示「命令正在运行」。App 首页把还能批的请求排在前面，过期的不再盖住它们。
- **内置 OpenCU 安卓引擎升到 0.9.1。** 批量操作不会再把下一步点进还没打开的对话框，打开对话框的调用能直接拿到里面的控件，低于 Android 14 的手机会直接说明版本不支持。act 的帮助和 skill 也写明了：安卓上先 `agent_desktop start`，因为批准审批要占手机前台。

兼容性：限权令牌要求 relay 和设备都是 v0.30.0 或更新，旧版会拒绝它。手机上的修复要把 App 更新到 v0.30.0（在 App 里「检查更新」）。一次数据库迁移 `016_scoped_tokens.sql`（只新建一张表）；回滚到旧镜像不用恢复数据库，已发的限权令牌会失效，不会获得更多权限。没有新增环境变量。

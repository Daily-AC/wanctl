# v0.28.0 — 在设备页升级 wanctl，给 Windows 设备装 OpenCU

- **在设备页升级 wanctl。** 设备主人在设备详情的版本旁点「升级」，填一个比当前版本新的正式版或 beta，设备用和 `wanctl update` 相同的签名校验下载、替换并重启，页面依次显示下载、安装、完成或失败原因。不能装相同版本，也不能降级；设备关了自动更新，主人的这次升级照样执行。分享给别人的设备、管理员查看别人的设备都没有这个按钮。
- **在 Windows 设备上装 OpenCU。** 「安装」为当前登录的控制台用户装上 OpenCU，「更新到最新版」更新已有的安装，用的是官方安装脚本，信任来源和手动安装相同。要先在设备上登录，并结束正在进行的桌面操作。
- 设备在线时装好 OpenCU，门户里的版本随即更新，不用等设备重连。
- 加固了审批、账号停用和设备回传文本的转义。

兼容性：网页升级要求设备上的 agent 是 v0.28.0 或更新；旧 agent 会提示在设备上运行 `wanctl update`，开着自动更新的话它也会自己升上来。门户只发包名和版本，下载地址和校验由设备自己完成。安装进度只保存在门户内存里，门户重启后消失。没有数据库迁移，没有新增环境变量。

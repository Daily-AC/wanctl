# v0.5.1

**下载页现在提供带扩展名、解压后可直接使用的构建产物。**

## 修复

- 「全部构建产物」不再把 macOS、Linux 和 Android CLI 的裸二进制直接交给浏览器，而是下载 `.tar.gz` 压缩包。每个压缩包里都是名为 `wanctl` 的对应平台可执行文件；Windows 仍下载 `.exe`，Android App 仍下载 `.apk`。

- 裸二进制继续随 release 发布，现有 `install.sh`、`install.ps1` 和 `wanctl update` 的地址与校验协议没有变化。压缩包作为额外的签名 manifest 产物发布，旧版客户端会忽略它们，不会影响升级。

- relay 的 `/dl/*` 下载响应现在显式携带 `Content-Disposition` 文件名。经过浏览器或反向代理下载时，不再依赖客户端从 URL 猜文件名。

## 自建部署提醒

- 没有数据库迁移，也没有新的配置项。
- relay 和 portal 都要重建，并把签名 release 目录一起换成 v0.5.1；只更新 portal 会让新的 `.tar.gz` 链接指向尚未发布的文件。

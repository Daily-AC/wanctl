# v0.20.2 — 手机上直接审批，提权状态说真话

- **手机 app 首页直接处理待审批。** 首页顶部多了「待审批」：设备、命令、发起方、剩余时间，点进去就是原来的详情页。不用再去通知栏里找；没有待审批时这一块不出现。
- **点完「允许一次」或「拒绝」，结果看得见。** 按钮先变成「提交中…」，再换成明确的结果：「已允许，命令正在执行」「已拒绝」「这条已在别处处理」「已过期」。10 秒还没送达，会说「还没送达」并给一个「重新提交」；手机联网后也会自动重发。
- **审批提醒的引导补全。** 设为审批手机后，引导页最上面先讲「在最近任务中锁定 wanctl」：从最近任务上划会直接停掉 wanctl，手机随即掉线、收不到审批。接着是横幅、锁屏、铃声、振动四个开关，最后发一条测试提醒，要你确认「响了，也看到了横幅」才算设好；选「没有」直接带到 wanctl 的通知设置页。没确认之前，首页会提示「审批提醒还没确认响了」。
- **提权通道和 ADB 显示真实状态，手机和门户一致。** app 的「提权通道」开关还是主人同意提权的那道闸，下面多一行状态：「已连通」，或「已允许，但还没连上无线调试，按指引配对后生效」。打开开关的按钮改成「允许（配对后生效）」。门户设备设置里的「ADB 配对」改成常驻的「ADB 无线调试」卡片：已连通、无线调试没开（重新打开后自动恢复，不用重新配对）、配对失效（点「重新配对」直接出表单）、手机上提权通道没开，四种状态一眼看清。状态由手机上的 agent 自己探测，每分钟、端口一变、配对一完成都会更新。
- **连接卡死后更快恢复。** agent、控制端和中继之间的 HTTP/2 连接现在会做健康检查：30 秒没收到任何数据就探一下，15 秒内没回应就换一条新连接。以前网络路径断了而连接没报错时，后面的请求会一直排在这条死连接上，可能好几分钟都连不上。
- **用过 exec 的设备能自动升级了。** 以前 agent 只要被普通 `wanctl exec` 调用过一次，就会留一个空闲的 shell，自动更新把它当成「正忙」，每 5 分钟推迟一次、永远升不上去，日志里也什么都不写。现在只有命令正在执行时才算忙；推迟时日志会写一行原因和次数。**已经停在旧版本的设备不会自己升到 v0.20.2**：在那台设备上手动运行一次 `wanctl update`，或者重启一次 agent，之后的版本就能自动升级了。

兼容性：手机 app 需要更新到 v0.20.2 才有首页待审批、结果反馈、新引导和提权状态行；门户的 ADB 状态卡片要求手机 app 也是 v0.20.2，旧版 app 仍只显示配对表单。无数据库迁移，无新增环境变量。

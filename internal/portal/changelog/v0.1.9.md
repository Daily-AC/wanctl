# v0.1.9

**在手机 Termux 里用 wanctl，现在是真的能用了。** v0.1.7 虽然带了安卓安装包，但装上去之后基本用不了；这一版把四个问题一次修完。

只影响安卓上用 Termux 的情况。其他系统（Windows / macOS / Linux）行为完全没变，用 `adb` 装在安卓上的也一直不受影响。

## 修了什么

**装完之后敲什么都报错。** 敲 `wanctl version` 会得到 `unknown command "/data/data/com.termux/..."`。原因是 Termux 启动这类程序时会在参数前面多塞一个路径，v0.1.7 只认得写全路径和 `./wanctl` 两种敲法，偏偏认不出直接敲 `wanctl` 这一种——而这是装完之后所有人都会用的那一种。

**`wanctl update` 会升级错东西（重要）。** 程序找"自己在哪"时拿到的是安卓的系统链接器路径，而升级操作会覆盖它拿到的那个文件。在**已 root 的设备**上，这会覆盖掉安卓系统的核心组件，后果很严重。没 root 的设备会因为权限不足而失败，不会造成损坏。

> 如果你手机上装的是 v0.1.7，**不要用 root 身份执行 `wanctl update`**。请改成重新跑一遍一行安装命令。

**`wanctl start` 起不来。** 报 `permission denied`——安卓不允许程序去启动自己所在的那个目录里的文件。现在换了一种安卓允许的启动方式，后台常驻可以正常用了。

**设备名字都一样。** 所有 Termux 设备都会显示成 `wanctl-agent`，多台设备互相撞名——而这个名字功能本来就是为了解决撞名。现在能正确读到手机型号了（比如那台平板显示为 `pa2353`）。

## 怎么升级

重新跑一遍一行安装命令即可（命令在「下载安装」页，带着你这个实例的地址）。

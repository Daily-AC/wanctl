# v0.16.0 — 访问申请通过后，邮件告诉你

配置邮件的实例现在会在管理员通过访问申请后发一封通知，里面有直接登录门户的链接，不必反复回来查看。登录时会向 GitHub 新增申请 `user:email` 权限，只读取已验证的主邮箱，用于账户通知；GitHub 没有可用邮箱时，可以在申请表里选填一个。管理员会在审批卡片中看到收件邮箱。拒绝申请不发邮件。

邮件是可选功能：未配置时，登录仍只读取公开资料，不申请邮箱权限。自部署可使用任意支持 TLS 的 SMTP 邮箱，需设置 `WANCTL_SMTP_ADDR`、`WANCTL_SMTP_USER`、`WANCTL_SMTP_PASSWORD` 和 `WANCTL_MAIL_FROM`。新增数据库迁移保存申请邮箱，升级 relay 时自动执行。

relay 和门户的容器镜像从这一版起由 GitHub Actions 从发布 tag 构建，用 cosign 按 digest 签名，推到 `ghcr.io/daily-ac/wanctl:v0.16.0`。自部署可以直接拉这个镜像，先验签再运行，命令见 `docs/release-signing.md` 的「Container image」一节。设备的自动更新不受影响。

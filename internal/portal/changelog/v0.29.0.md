# v0.29.0 — 用 act 操作安卓手机

- **act 支持安卓手机。** 装了 wanctl App、开着提权通道、并有可用的无线调试配对或 root 的手机，可以用 `wanctl act --target <手机> --discover` 列出 OpenCU 安卓引擎的工具，再按编号点击、输入、滑动、截图。引擎以 shell 身份运行，可以在后台虚拟屏上操作，不占用人正在用的主屏。
- 审批、控制端身份、设备忙锁和十分钟空闲关闭沿用现有 act 规则。人在手机上连按三次音量下键会停住 agent，之后要重新取得明确批准才能继续。
- 首次使用时，手机从 OpenCU 官方 GitHub 最新 release 下载安卓引擎，大小和 SHA-256 都核对通过才会使用，并缓存在 App 自己的目录里；控制端的文件读写碰不到这个缓存。

兼容性：手机上的 wanctl App 要更新到 v0.29.0（在 App 里「检查更新」）。Termux 和独立二进制不支持安卓 act，旧版 `actions[]` 仍只支持 Windows。没有数据库迁移，没有新增环境变量。

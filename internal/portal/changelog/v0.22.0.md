# v0.22.0 — 以服务方式装的 Windows agent 也能截图和操作桌面了

- **服务和 SYSTEM 计划任务装的 agent 也能用 `wanctl screenshot` 和 `wanctl act` 了。** 这类 agent 跑在 Windows 的会话 0 里，以前看不到桌面，截图会报错或给一张空白图。现在每次截图或 `act`，agent 都在屏幕前那个登录用户的会话里临时起一个助手进程来做，做完就退出。助手用的是这个用户自己的权限和环境，不会比用户本人权限高，也不会提权。不新增常驻进程、计划任务或服务，安装方式不变。
- **只认当前坐在屏幕前的那个登录会话。** 物理屏幕上没有用户登录时（包括只有远程桌面会话的情况），返回明确的错误「no signed-in user at the active console」，不会去操作远程桌面会话。锁屏或安全桌面（比如 UAC 确认框）在前时，和以前一样返回「已锁定或安全桌面」的错误。截图之后如果切换了用户或注销重登，旧的截图编号作废，要重新截图。
- **旧版控制端截图也能拿到真实画面了。** 旧版控制端对这类 agent 截图，以前拿到的是一张空白图，现在是真实屏幕（PNG，长边最多 1280 像素）。
- **活动日志记下助手在哪个会话里运行**（`desktop_session` 字段），打字内容照旧不落盘。

v0.21.0 的提示条、有人动就停、和 exec 同一道审批这些规则不变。两条已知限制照旧：
- 打字过程中如果别的程序突然抢到前台，最多可能有 1 个字落进那个窗口，随后立刻停下并报错，不会继续打。
- 以管理员权限运行的窗口在前台时，`act` 切不走它，也不会对它点击或打字。遇到这种情况要请电脑前的人先切开。

兼容性：只需要升级 Windows 上的 agent；relay 和控制端没有变化，v0.21.0 的控制端可以直接用。服务方式的 agent 要以 LocalSystem 身份运行（SYSTEM 计划任务、LocalSystem 服务都是）。无数据库迁移，无新增环境变量。

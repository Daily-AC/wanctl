# v0.1.3

安装重新变回一行命令。

- **一行装完**。安装脚本自带它对应的中继地址，只有想装到别的中继时才需要额外设置。
- **装的时候不用再自己折腾 OpenSSL**。校验签名多了一份 RSA 版本专供安装脚本：macOS 自带的 LibreSSL 验不了原来那种签名，Windows 的 PowerShell 5.1 更是完全没有，导致在原装 Mac 上一行安装直接失败、在 Windows 上得先慢慢下一个 OpenSSL。
- **WebSocket 模式下的 agent 现在能被正常停掉**。设备空闲时它卡在一个永远不返回的读取里，`wanctl stop` 完全没反应，只能等系统超时强杀。
- **不想手动下载再运行也能装上**，中继会提供一行安装命令，来自同一个签过名的发布目录。

# v0.12.1 — MCP 工具声明输出结构

- **8 个开发工具增加 Output Schema。** workspace、peers、exec、exec_async、exec_poll、read、write 和 edit 现在向宿主声明结构化返回的字段、类型和含义。普通命令、后台任务与文件操作补上 `structuredContent`；已有的文本结果、工具名、输入参数和 CLI 输出保留。
- **把容易混淆的状态分开说明。** 工作区生命周期看 `state`，命令是否完成看 `done`；退出工作区时 `state=closed`、`done=false` 是正常结果。命令退出码只在命令完成后解释。普通设备执行和工作区执行分别声明自己的结果格式，普通后台提交只返回已接受的任务 ID，不猜测任务是否完成。
- **文件摘要和续读信息可直接供下一次调用使用。** 读取返回正文、行范围、整个文件的大小与 SHA-256；编辑和写入返回修改后的摘要。文件读取使用行偏移，命令轮询使用字节偏移，超长行无法继续无损分页时不会给出误导性的下一页偏移。
- **声明经过实际返回校验。** MCP 服务启用输出校验；测试会从真实 `tools/list` 读取 Schema，再校验经由 HTTP 和 stdio 返回的数据。覆盖空结果、运行中任务、非零退出码、截断、摘要冲突和工作区关闭。已有诊断错误继续使用 `isError` 和原有提示，不会伪装成成功结果。

本次主要更新控制端和托管 MCP 服务；使用 v0.12.0 的受控设备即可配合。无数据库迁移、无新增环境变量，也不改变设备授权或宿主审批流程。输出字段说明见 `docs/mcp-output.md`。

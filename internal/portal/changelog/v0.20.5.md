# v0.20.5 — Windows 缩放屏上的截图完整了

- **Windows 显示缩放不是 100% 时，`wanctl screenshot` 能截到整个屏幕了。** 以前在 125% 缩放的屏幕上只截到左上角 80% 的区域（1920×1080 的屏幕截出来是 1536×864），右边和下边（包括任务栏）都缺。原因是截图用的 PowerShell 进程没有声明 DPI 感知，Windows 给它的是缩放后的逻辑尺寸。现在截图前先声明 DPI 感知，截出来的尺寸等于物理分辨率。

兼容性：只改了 Windows 截图；缩放屏上的截图会比以前大（等于物理分辨率）。无数据库迁移，无新增环境变量。

# v0.3.1

**32 位机器也能装了：发布矩阵从 6 个平台扩到 15 个，安装脚本按系统和 CPU 自动挑包。**

## 新增的平台

| 系统 | 新增 |
|---|---|
| Linux | x86 32 位（386）、ARM 32 位（armv6 / v7，树莓派 Zero / 1 到各路开发板）、MIPS 大小端（softfloat，路由器） |
| Windows | x86 32 位、ARM64（骁龙本） |
| Android | ARM 32 位、x86、x86_64——每个都带独立的 APK 和终端二进制 |

macOS 没有 32 位包：Go 早就去掉了 darwin/386，Catalina 以后的系统本身也不跑 32 位程序，Intel 和 Apple 芯片两个包已经覆盖所有 Mac。

## 一行安装自动选包

`install.sh` 按 `uname -m` 映射到对应架构（MIPS 还会探测字节序），`install.ps1` 先看系统位数、再看 CPU 是 x64 还是 ARM64——在 ARM64 机器上用被模拟的 x64 PowerShell 跑，也会装原生 ARM64 版而不是慢的模拟版。装错架构的路被堵死：清单里没有这台机器的包就明确报错。

## 安卓：每个 ABI 一个 APK

门户下载页的大按钮仍是 ARM64（几乎所有手机平板都是它），下面多了 ARM 32 位 / x86 / x86_64 三个小链接。装哪个 APK，App 内的「检查更新」就跟着哪个：二进制知道自己的架构，不会把 32 位机器升到 64 位包上去。已装的 ARM64 App 升级路径不变。

## 顺带

发布矩阵现在只写在一个地方（`scripts/release-targets.sh`），发布构建、发布前的文件清单校验、CI 的交叉编译门禁都从它读；以后加平台改一行。

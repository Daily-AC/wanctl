# v0.22.1 — Windows 锁屏时截图和操作改为报错

- **锁屏时不再截到锁屏画面，也不再接受操作。** Windows 10/11 的锁屏画在普通桌面上，以前只检查当前输入桌面，所以锁屏时 `wanctl screenshot` 会返回一张锁屏画面，`act` 也会被接受。现在改用系统记录的会话锁定状态判断：锁屏时截图和 `act` 都返回「desktop unavailable: screen locked or secure desktop active」，不给图、不发输入；操作进行到一半时锁屏，下一步输入之前就停下。v0.21.0 和 v0.22.0 都有这个问题，用户桌面会话里的 agent 和服务方式装的 agent 都已修好。
- **旧版控制端截图也一样。** 旧版控制端走旧的截图路径，锁屏或安全桌面（比如 UAC 确认框）在前时，同样返回这个错误，不再给图。
- **更正：** v0.22.0 的说明写了「锁屏时和以前一样返回错误」，这一条要到本版才成立。

兼容性：只需要升级 Windows 上的 agent；relay 和控制端没有变化。无数据库迁移，无新增环境变量。

# v0.1.10

**安卓端现在是一个能装的 App 了。** 不用装 Termux、不用敲命令，装上点两下就能用，而且**重启之后会自己回来**——这是之前 Termux 那条路一直做不到的。

其他系统（Windows / macOS / Linux）有两处改动，见最后一节。

> 如果你是 8 月 6 日之后从下载页装的：那阵子服务器上还是 v0.1.7，安卓版有个严重问题（在已 root 的手机上执行 `wanctl update` 会覆盖系统组件）。请务必升级。

## 新的安卓 App

装好打开，点「登录」在浏览器里确认一下，设备就注册好了。App 里能看状态、看指纹、看日志，也能直接检查更新。之后的升级在 App 里点「检查更新」就行。

下载地址：

```
https://wanctl-relay.***REMOVED***.***REMOVED***.com/dl/wanctl-android-arm64.apk
```

原来用 Termux 装的可以继续用，也可以换成 App——换完把 Termux 里那个卸掉即可。

## 装完请务必做这一步

**设置 → 电池 → 后台耗电管理 → wanctl → 允许后台高耗电。**

不做这一步，在国产手机上会是这样：设备明明注册好了，息屏两分钟左右就再也连不上，而且**不报任何错**——系统把 App 整个冻住了，它连"我连不上"都说不出来。

这条不是保险起见才写的。我们在 vivo PA2353 上量过：系统的省电豁免、自启动、前台服务、唤醒锁四样全开，息屏 2 分钟照样被冻结；只有把这个开关改成「允许后台高耗电」才能一直在线。换句话说，决定手机能不能常在线的不是 wanctl 也不是安卓本身，是厂商这个开关。

App 里的「电池」按钮会直接带你到对应设置页（vivo / OPPO / 小米 / 华为）。

另外，安卓的开机自启是"尽力而为"的——我们测的四次重启里有一次系统没有派发。App 里有个 15 分钟的兜底任务，最坏情况下会晚一刻钟回来。

## 所有平台

**设备离线时终于说得出原因。** 之前 agent 连不上中转服务器会默默重试，日志里什么都不留，"网络不通"和"被系统冻结"看起来一模一样。现在会写明第一次失败、之后大约每分钟一条、以及恢复。

**`wanctl update` 不再删你机器上的其他文件。** 老版本升级完会把 `PATH` 上所有叫 `wanctl` 的文件删掉，判断依据只有文件名——你自己写的包装脚本、你编译的开发版，都会被顺手删掉；而在需要 sudo 的机器上它是以 root 身份删的，删得掉一切。现在它只会提示你"直接敲 `wanctl` 实际跑的是另一个"，一个文件都不动。

## 怎么升级

已经装好的（含 Termux、电脑端）：

```sh
wanctl update
```

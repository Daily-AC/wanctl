# v0.1.4

修掉三处「明明失败了却报成功」。

- **一行安装在所有平台都装不上**。安装脚本会去中继取一个签名文件，而中继恰好不肯给这一个文件，于是安装还没开始下载就 404 中断了。v0.1.3 发布出去的东西本身没问题，是中继不发。
- **升级说成功，其实没换**。当设备的 agent 是由别的账户在跑（Windows 计划任务用 SYSTEM、systemd 用 root），你手里的 `wanctl update` 根本杀不掉它，却照样打印「已安装」。现在它会当场拒绝并告诉你该重启哪个服务，或者确认新进程真的接管了才说成功。
- **被拒绝时只看到连接断开**。设备拒绝一个会话后立刻关连接，拒绝理由和配对链接会在路上被冲掉，控制端只能看到一个 EOF，不知道为什么被拒、也拿不到该去点的那个链接。

## 升级说明

修的是升级器自己，所以从 v0.1.3 升上来时用的还是旧升级器，那一次可能仍然会假报成功——升完用 `wanctl status` 确认进程真的换了。从 v0.1.4 往后就会说实话。

# v0.2.4

**`wanctl service install` 装出来的开机自启服务，现在自带 relay 地址了。**

服务管理器（systemd / launchd / 计划任务）不读你 shell 里 `export` 的环境变量，而开源发布的二进制又没有内置地址——结果就是照文档装好的服务，机器一重启 agent 就找不到中继（[issue #2](https://github.com/Daily-AC/wanctl/issues/2)）。

现在 `service install` 会把当时生效的 relay 地址和传输方式直接写进服务单元（也可以用 `--relay` / `--transport` 显式指定）；解析不出可用的 relay 地址时会直接拒绝安装，而不是装一个每次开机必死的服务。之前手工补过 `Environment=` 的单元不受影响，重装一次即可换成新格式。

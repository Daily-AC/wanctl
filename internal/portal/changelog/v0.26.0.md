# v0.26.0 — 有了 beta：`wanctl update <版本>` 安装指定的签名版本

- **`wanctl update <版本>` 安装指定的签名版本。** `wanctl update v0.26.0-beta.1` 加入 beta，`wanctl update v0.25.0` 回到某个正式版。和自动更新一样先验签名清单和 SHA-256，装好后按原方式重启运行中的 agent：macOS launchd、Linux systemd、`wanctl service install` 装的 Windows 计划任务都实测过。已在运行该版本时直接退出。降级时会提示：auto_update 开着的话，下次自动检查会装回最新正式版。
- **装了哪个版本，就在哪个渠道。** 正式版只会自动更新到更新的正式版；beta 接受更新的 beta 或正式版，所以对应的正式版发布后，beta 设备会在下次检查时自己回到正式版。没有渠道配置项，退出 beta 就是 `wanctl update <当前正式版>`。
- **beta 只从 GitHub 发布页下载。** relay 的 `/dl` 镜像只放正式版，够不到 GitHub 的设备装 beta 时要给这条命令设 `HTTPS_PROXY`。`release_base` 以 `/releases/latest/download` 结尾时，指定版本改从 `/releases/download/<版本>` 下载。
- **发版先过 beta。** 每个正式版先以 `vX.Y.Z-beta.N` 发成 GitHub 预发布，只有桌面二进制，没有安卓 APK 和容器镜像，在维护者的设备上跑满 24 小时、各种装法都能升级和重启之后，才在同一个提交上打正式版。发版流水线会拒绝不落在 beta 提交上的正式版。

兼容性：只改了 `wanctl update` 和自动更新的选版规则，新旧版本可以混用，正式版设备的自动更新行为不变。无数据库迁移，无新增环境变量。

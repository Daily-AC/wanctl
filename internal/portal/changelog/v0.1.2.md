# v0.1.2

修 agent 自我升级时的进程归属问题。

- **升级后仍然由原来的服务管着**。以前替换完二进制会另起一个脱离管控的新进程，systemd / launchd / Windows 计划任务就此失去对它的掌控。现在升级会把旧进程交还给原本的服务去重启，中继地址、传输方式、审批模式、身份和环境都保持不变。
- **Windows 计划任务加了重启循环**，它原生的「登录时触发」并不会在进程后来退出时把它拉起来。
- **不再把过期的进程号当成活着的 agent**。

## 升级说明

从 v0.1.1 或更早升上来后，请执行一次 `wanctl service install`，把已有的开机自启配置迁移到新形式。全新安装不需要这一步。

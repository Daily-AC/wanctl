# v0.1.8

修一个 v0.1.7 带来的问题：**在 Termux（手机上的终端 app）里装好的 wanctl，敲什么命令都报错。**

## 症状

在 Termux 里装好之后，敲 `wanctl version`（或任何命令），得到的是：

```
unknown command "/data/data/com.termux/files/usr/bin/wanctl"
```

看起来像是装坏了，其实二进制是好的——是参数被整体挪错了一位。

## 为什么会这样

安卓上 Termux 在启动这类程序时，会在参数列表最前面多塞一个程序自己的路径。v0.1.7 已经处理了这种情况，但判断方式有个盲点：它只认得 `./wanctl` 和写全路径这两种敲法，认不出直接敲 `wanctl` 这一种——而后者恰恰是装完之后所有人都会用的那一种。

现在三种敲法都认得了。

## 影响范围

只影响在 Termux 里用的安卓设备。其他系统（Windows / macOS / Linux）完全不受影响，行为一模一样。用 `adb` 装在安卓上的也不受影响。

## 怎么升级

如果你已经在 Termux 里装了 v0.1.7，`wanctl update` 这条命令本身也会踩到同一个问题，所以请写一次全路径：

```sh
$PREFIX/bin/wanctl update
```

或者重新跑一遍一行安装命令。

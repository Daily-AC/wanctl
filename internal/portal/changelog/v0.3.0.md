# v0.3.0

**wanctl 和部署配置解离了：工具从 GitHub 装，装完告诉它你的实例在哪。**

## 分发全面切到 GitHub Releases

安装脚本、二进制、`wanctl update` 的升级源，现在都指向项目的 [GitHub Releases](https://github.com/Daily-AC/wanctl/releases)——与任何中继相互独立，也因此天然是干净的信任起点（此前「从中继下载的安装脚本没法为中继背书」的告诫可以退休了）。中继的 /dl 镜像保留为内网部署的可选项：设了 `WANCTL_RELAY` 的安装命令、以及没烤发布页地址的自编译二进制，仍走镜像。

## 新命令 `wanctl config`

实例地址不再靠每条命令前面挂环境变量：

```
wanctl config set relay=https://relay.example.com portal=https://portal.example.com
wanctl config           # 查看生效值和来源
wanctl config unset …   # 删除
```

优先级：命令行 flag > 环境变量 > 这里的配置 > 编译期默认值。`transport` 也可持久化（比如固定走 ws）。

## 首次使用会引导配置

装完直接跑 `wanctl`（或 `wanctl login`），没配过地址的话会在终端里问你一次并存下来；脚本和 AI 驱动的非交互场景不会挂住等输入，而是直接给出要跑的 `wanctl config set` 命令。

# v0.3.2

**修复：一行安装在 OpenWrt 路由器（精简 busybox）上装不上。**

v0.3.1 把路由器纳入了发布矩阵，安装脚本却在第一台真实路由器（GL.iNet，OpenWrt，aarch64）上就摔了：`signed manifest has no unique Linlx/arm64 artifact`。

## 三处 busybox 兼容修复

- **系统名探测**：OpenWrt 的 busybox 编译时没开 `tr` 字符类，`tr '[:upper:]' '[:lower:]'` 被当成逐字符映射，`Linux` 变成 `Linlx`。改为直接 `case` 匹配 `uname -s`。
- **MIPS 字节序探测**：原来用 `od`，而 OpenWrt 根本没有这个命令。改为读 `/bin/sh` 的 ELF 头（第 5 字节 1=小端、2=大端），只用 `dd` 和 `tr`。
- **落盘**：原来用 `install`，busybox 路由器也没有。改为 `cp` + `chmod` + `mv` 重命名，顺带能替换正在运行的二进制。

脚本开头现在会明确指出缺什么：OpenWrt 上提示 `opkg install curl openssl-util`。

## 本次验证

在真实 OpenWrt rootfs（busybox）里跑修复后的脚本，从中继下载、验签、按架构选包、落盘全程通过；Mac/Ubuntu/Windows 一行安装回归不变。

## 已经装不上的机器怎么办

v0.3.1 的安装脚本已被这一版替换，重新跑同一行安装命令即可，不用改任何东西。

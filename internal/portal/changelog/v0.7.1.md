# v0.7.1 — 升级后设备不再"变成新设备"，共享设备可被发现

升级 CLI 之后设备在门户里显示离线、旁边多出一台同名或叫 `bogon` / `localhost` 的新设备：这是中继按"名字 + 指纹"找旧记录，而 macOS 的内核主机名会随网络变化，名字一变就被当成新设备。本版改为按证书指纹认设备，名字只是标签。

- 中继按证书指纹把旧记录提升为新的设备 ID，别名、共享授权与历史一并保留；同名但指纹不同的旧 agent 不会冒领。
- macOS 上默认设备名改用系统设置里的本地主机名（`scutil --get LocalHostName`），不再随 DHCP 漂成 `bogon` 或 `localhost`。
- `wanctl peers` 新增"shared with you"一段，列出别人共享给你的设备，直接以 `owner/device` 形式给出，可原样填进 `--target`；只写设备名时会先在自己的命名空间找，再在共享给你的设备里找，两边都命中才要求写全名。
- 目标不存在时中继不再只回一句 `forbidden`，而是说明该命名空间里没有这台设备、共享设备要写成 `owner/device`。
- 门户：非管理员不再看到「邀请」页签；共享给你的设备页不再出现主人的齿轮按钮，也不会误打开上一台设备的设置；共享授权表里设备标签与名称之间加了分隔；空表提示居中。
- 门户头部的版本号现在能正确显示 v0.7.0 之后的版本；发版脚本会在缺少更新说明时拒绝出包。

**已升级到 v0.7.0 的设备会自动更新到本版；已经"分裂"成两条记录的设备由中继管理员合并一次即可，agent 侧无需操作。**

# v0.2.0

**wanctl 开源了：[github.com/Daily-AC/wanctl](https://github.com/Daily-AC/wanctl)，Apache-2.0。这一版把它从「一家公司的内部工具」变成「任何人都能自己部署的产品」。**

## 登录变成双模式

原有的企业 SSO（反代注入 header）照旧；新增 GitHub OAuth——自部署实例拿一个 GitHub OAuth App 就能开张，命名空间就是你的 GitHub 用户名。

## 准入是邀请制

全新部署里第一个登录的账号自动成为管理员；之后的人凭一次性邀请码、或管理员预录的 GitHub 用户名进来。没被邀请的人登录后停在等待页，不会建立命名空间。

## 好友机制

跨账号的设备共享从这版起要先加好友：按 GitHub 用户名**精确查找**（不能模糊搜索，陌生人枚举不到你）发请求，对方接受后才能互相授权。共享可以只给部分能力（比如只许 exec 和拉文件）；**删除好友会级联撤销双向的全部授权**。

## 自部署一条龙

`selfhost/` 里一份 docker compose 拉起 relay + 门户 + Postgres 三个容器，数据库结构启动时自动建好；`docs/self-hosting.md` 从零写到「第二台设备被远程 exec」。发布流水线搬到 GitHub Actions，签名密钥全部换新（Ed25519 清单签名 + RSA 脚本签名的双轨验证不变）。

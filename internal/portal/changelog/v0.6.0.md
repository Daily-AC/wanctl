# v0.6.0 — 手机接入与独立设备身份

Android 首次打开会引导通知与后台设置，再选择官方或自建服务、登录和启用。首页保留连接状态与启停按钮，Logo 随连接状态呈现轻量动效；设备、权限和高级选项收进分组设置。

- Android 设备的门户设置新增 ADB 配对表单，填写手机配对弹窗的端口和六位码即可配对。
- 门户删除设备后立即更新列表，无需手动刷新；过期列表请求不会把旧卡片带回来。
- 门户支持授权后返回 App，移动端登录状态会经过 OAuth 和邀请码流程保留。旧门户仍可使用一次性授权码。
- 预览包明确说明手动更新方式；正式签名的 APK 保留验签更新。
- 门户可用 `WANCTL_GITHUB_PROXY` 单独配置 GitHub 授权请求的出站代理，不改变中继或其他请求的路由。
- 每次安装拥有独立的持久 UUID。设备名与别名可以重复或修改，不再覆盖同名设备的连接、权限和信任记录。

**部署顺序：先备份数据库，再一起升级 relay 和门户，最后升级设备与控制端。** 迁移 007 修改数据库结构；回滚需要恢复对应的数据库快照和旧二进制。旧设备可以继续使用原路由，新设备首次升级时通过原名称与证书匹配迁移记录。
